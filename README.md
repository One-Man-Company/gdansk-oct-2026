# Gdańsk — 24–26 October 2026

A weather-proofed three-day plan for five friends, built as a single static page.

- Hour-by-hour forecast analysis (Open-Meteo), with go/no-go verdicts per day
- 63 mapped places (MapLibre + OpenFreeMap, no API keys) with prices, October opening hours and booking notes
- Three-day itinerary with indoor alternatives for the storm on Sunday
- Transport decision tables (airport → flat, trams, SKM, Uber/Bolt, car rental, parking)
- Budget scenarios, closure matrix, practical info

Open `index.html`. No build step, no dependencies except the MapLibre CDN.

Prices and hours verified 23 October 2026 from official sources; re-check anything you are about to pay for.
