# Šeškinė Trip — Gdańsk, 24–26 October 2026

A weather-led three-day plan for five friends, as a single static page.

- **162 places** — sights, museums, nature, restaurants, cafés, bars, activities, day trips
- **152 live Google Maps ratings**, shown on every row and in the map popups
- Hour-by-hour weather analysis (Open-Meteo) with a go/no-go verdict per day
- Three-day itinerary with indoor alternatives for the storm on Sunday 25 Oct
- Transport decision tables (airport → flat, trams, SKM, Uber/Bolt, car rental, parking)
- Budget scenarios, opening-hours matrix, practical info
- Interactive MapLibre map (OpenFreeMap, no API keys) with category filters and clustering

Single `index.html`, no build step. Open it or serve it.

Prices and hours verified 23 October 2026 from official sites. Ratings fetched from Google Maps the same day.
